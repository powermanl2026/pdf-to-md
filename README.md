# PDF-to-Markdown Skill

This skill converts PDF documents to Markdown format, preserving the directory structure and providing a readable text representation.

## Installation
The skill uses `pdfminer.six`, which is already available in the Claude Code environment.

## Usage
See `SKILL.md` for detailed usage instructions.

## Script Location
The conversion script is located at `scripts/convert_pdf_to_md.py`.
